# Unified AI App 源码培训

基准日期：2026-10-16。以当前 `src/application`、`src/platforms`、`src/boards` 目录和源码为准。

这套教材面向第一次接触本项目的开发者，也可以用于结合代码讲解架构。先读职责，再追踪一条业务路径，最后看平台差异和错误处理。教材不要求先掌握全部驱动或 SDK 内部实现。

## 2. 每节怎样使用

1. 先读“学习目标”，不要一开始展开所有头文件。
2. 按“源码阅读顺序”打开文件，先读公开接口，再看关键实现。
3. 对照调用图查找函数；图表示的是指定视角，不一定是 `#include` 关系。
4. 完成练习，先独立回答，再对照参考答案。
5. 讲解时说清“这个函数由谁调用、在哪个线程运行、数据由谁持有”。

所有源码链接相对于当前 Markdown 文件；仓库整体移动后仍可使用。正文使用函数名定位，不把易过期的源码行号写死。展示的是实际片段时会说明，省略的教学伪代码不能直接替换实现。

## 3. 新手先认识这些词

| 词语 | 在本项目中的含义 |
|---|---|
| SDK | 供应用调用的软件库；本项目既用芯片 SDK，也用 ConvAI SDK，应说清是哪一个 |
| BSP | 板级支持包，可能同时提供驱动、系统服务和构建逻辑；范围可能大于本仓库 `boards` |
| HAL | 将 SDK 所需的线程、时间、网络、TLS 等操作接到实际平台的适配层 |
| 回调 | 把函数地址交给另一模块，由对方在适当时机调用 |
| `ops` | 一组函数指针形成的能力契约，如 `ai_media_ops_t` |
| `ctx` | 回调携带的上下文指针；由实现解释，公共调用者无需知道其具体结构 |
| owner | 独占某对象修改权的执行上下文；本项目状态机由应用事件循环串行驱动 |
| 快照 | 某时刻复制出的状态；不是把对象的所有权交给另一个线程 |
| 屏障 | 函数返回前保证某类旧操作已经停止；这里不是单指 CPU 内存屏障指令 |
| 单调时间 | 用于计算间隔的时间基准，不随 NTP 校时跳变 |
| 测试替身 | 主机测试里替代真实 SDK、存储或设备的实现，不等于真实硬件 |

## 4. 阅读和实验边界

- 教材以当前实现解释代码，不代表所有历史问题均已解决。
- 润和长回答卡顿、Error -3、Listening 不识别仍在专项排查；新 TLS 交付诊断版已构建，尚未烧写验证。详见[验证记录](../validation.md)和[音频定位记录](../hoperun-audio-investigation.md)。
- Windows 模拟器属于 GoldieOS 运行环境，使用电脑网络与音频，不提供 Wi-Fi 配网。
- 单板统一测试协议、自动发现、串口控制与日志复用、test/release 独立构建属于设计规划，不应当成当前已经落地的能力。见[阶段 0 设计](../stage0-contracts.md)。
- 不在课堂截图、日志或练习文件中复制真实云鉴权信息和 Wi-Fi 密码。配置模板可以阅读，私人配置不作为教材附件。
- 本轮只生成教材，不修改产品源码、不重新烧写设备。
